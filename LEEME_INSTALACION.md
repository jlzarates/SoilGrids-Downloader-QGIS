# Instalacion Rapida

Ruta del proyecto:

```text
F:\DISCO D\10_AMBIENTA\PROYECTOS\PROYECTO FOREST-MAP TOOL\QGIS_PLUGIN_SOILGRIDS
```

Construir ZIP:

```powershell
cd "F:\DISCO D\10_AMBIENTA\PROYECTOS\PROYECTO FOREST-MAP TOOL\QGIS_PLUGIN_SOILGRIDS"
python build_zip.py
```

Instalar en QGIS:

1. **Complementos > Administrar e instalar complementos**.
2. **Instalar a partir de ZIP**.
3. Seleccionar:

```text
dist\SoilGrids_AOI_Downloader_0.1.1.zip
```

Abrir:

```text
Web > SoilGrids AOI Downloader
```
